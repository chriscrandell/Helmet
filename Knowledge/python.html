Python

The glue language for automation, scripting and quick tools. You already use it with Flask. This page is the cheat sheet plus the network-automation angle.

Setup

python3 -m venv .venv            # one virtual env per project
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install flask netmiko        # install into the venv
pip freeze > requirements.txt    # pin what you used
pip install -r requirements.txt  # rebuild elsewhere

Syntax cheat sheet

# data structures
nums  = [3, 1, 2]                 # list (ordered, mutable)
point = (4, 5)                    # tuple (immutable)
seen  = {"a", "b"}                # set (unique)
dev   = {"host": "sw1", "port": 22}  # dict

# comprehensions
squares = [n * n for n in nums if n > 1]
by_host = {d["host"]: d for d in devices}

# f-strings
print(f"{dev['host']:<10} port {dev['port']}")

# unpacking / enumerate / zip
for i, (name, ip) in enumerate(zip(names, ips), start=1): ...

# functions with defaults, type hints
def ping(host: str, count: int = 4) -> bool: ...

# files (always with a context manager)
with open("hosts.txt") as f:
    hosts = [line.strip() for line in f if line.strip()]

# exceptions
try:
    risky()
except (TimeoutError, ConnectionError) as e:
    log.warning("failed: %s", e)
finally:
    cleanup()

# classes / dataclasses
from dataclasses import dataclass
@dataclass
class Device:
    host: str
    platform: str = "cisco_ios"

Standard-library gems

  • pathlib: paths as objects (Path("logs").glob("*.txt"))
  • ipaddress: subnetting in code (example below)
  • json, csv: read and write structured data
  • subprocess: run system commands (subprocess.run([...], capture_output=True, text=True))
  • argparse: proper command-line tools
  • logging: use it instead of print in anything that runs unattended
  • concurrent.futures: run against 50 devices in parallel with a thread pool

Network automation

import ipaddress
net = ipaddress.ip_network("10.14.32.0/21")
print(net.num_addresses, net.broadcast_address)   # 2048 10.14.39.255
for sub in net.subnets(new_prefix=24):             # carve /24s
    print(sub)
ipaddress.ip_address("10.14.37.200") in net        # True
# Netmiko: SSH to network devices (pip install netmiko)
from netmiko import ConnectHandler
dev = {"device_type": "cisco_ios", "host": "10.0.0.1",
       "username": "admin", "password": getpass()}
with ConnectHandler(**dev) as conn:
    print(conn.send_command("show ip interface brief"))
    conn.send_config_set(["interface gi0/1", "description uplink"])

Never hard-code credentials. Use getpass, environment variables or a vault. Lab first, and get approval before pointing scripts at operational networks.
