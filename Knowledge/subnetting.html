The block-size method

  1. Find the interesting octet: the one where the mask isn't 255 or 0.
  2. Block size = 256 − mask value in that octet (e.g. /21 → 3rd octet 248 → block 8).
  3. Network = the largest multiple of the block size ≤ the address's value in that octet (37 → 32).
  4. Broadcast = next network − 1 (next is 40, so broadcast ends at 39 in that octet, with .255 after it).
  5. Usable = network + 1 through broadcast − 1.

Worked example: 10.14.37.200/21 → block 8 in the 3rd octet → network 10.14.32.0, broadcast 10.14.39.255, hosts 10.14.32.1 – 10.14.39.254 (2,046 hosts).

Wildcard mask (ACLs, OSPF network statements) = 255.255.255.255 − subnet mask, e.g. /21 → 0.0.7.255.

IPv6 essentials

  • 128 bits, 8 hextets. Drop leading zeros in a hextet, and replace one run of all-zero hextets with ::.
  • LANs are /64. A site typically gets a /48 or /56.
  • 2000::/3 global unicast · fe80::/10 link-local (every interface has one) · fc00::/7 unique local (fd00::/8 in practice) · ff00::/8 multicast · ::1 loopback.
  • No broadcast. ARP is replaced by Neighbor Discovery (ICMPv6).
  • Addressing options: static, SLAAC (prefix from router advertisements + interface ID), stateless DHCPv6 (extra options), stateful DHCPv6.
  • EUI-64: split the MAC in half, insert FFFE, flip the 7th bit of the first byte.
