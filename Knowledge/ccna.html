CCNA (200-301)

Cisco's associate-level networking cert: one exam covering fundamentals, switching, routing, services, security and automation. Valid for 3 years, renewed by retaking an exam or earning continuing-education credits.

Blueprint change on the horizon. Cisco has announced CCNA v2.0, first testing 3 Feb 2027. The current v1.1 exam stays available until then. If you'll be ready before early February 2027, study v1.1. Otherwise go straight to v2.0. Always confirm against the official exam topics on Cisco's site before booking.

v2.0 headline changes: it adds hypervisors/VMs/containers, IPv6 static routing and OSPFv3, HSRP/VRRP, SFTP/SCP, IPsec VPNs, and an AI-in-operations topic (agentic AI and prompt selection) alongside SNMP, syslog and Ansible.

Study checklist

Tick topics as you can explain them and configure them in a lab. Progress is saved in this browser.

  • OSI / TCP-IP models, TCP vs UDP, common ports
  • Cabling, interface errors (CRC, duplex mismatch, speed)
  • IPv4 subnetting by hand in under a minute: practice
  • IPv6 addressing types, SLAAC, EUI-64
  • VLANs, 802.1Q trunks, native VLAN, inter-VLAN routing (router-on-a-stick, SVIs)
  • Rapid PVST+: root election, port roles, PortFast, BPDU guard
  • EtherChannel with LACP
  • CDP / LLDP
  • Wireless: WLC architectures, AP modes, WPA2/WPA3
  • Reading the routing table: longest match, AD, metric
  • IPv4 and IPv6 static and floating static routes
  • Single-area OSPFv2 (and OSPFv3 for v2.0)
  • First-hop redundancy: HSRP (VRRP for v2.0)
  • NAT / PAT, DHCP, DNS, NTP, SNMP, syslog
  • Standard and extended IPv4 ACLs
  • Port security, DHCP snooping, dynamic ARP inspection
  • AAA, local users, SSH, (SFTP/SCP for v2.0)
  • VPN concepts (IPsec configuration for v2.0)
  • Automation: REST APIs, JSON, controller-based networking, Ansible
  • v2.0 only: AI in network operations
