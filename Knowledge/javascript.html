JavaScript

The language of the browser and of this site. This page covers modern syntax, async code, the DOM, and the step up to TypeScript/Angular.

Modern syntax

const max = 10;            // const by default, let when it changes, never var
let count = 0;

const add = (a, b) => a + b;                       // arrow function
const { host, port = 22 } = device;                // destructuring + default
const merged = { ...defaults, ...overrides };      // spread
const label = `${host}:${port}`;                    // template literal
const name = user?.profile?.name ?? "unknown";     // optional chaining + nullish

// array methods (no loops needed most of the time)
const ssh   = devices.filter(d => d.port === 22);
const hosts = devices.map(d => d.host);
const total = parts.reduce((sum, p) => sum + (p.cost ?? 0), 0);
const found = devices.find(d => d.host === "sw1");

// modules
export function parse(s) { ... }
import { parse } from "./parse.js";

Equality: always === and !==. Truthiness traps: 0, "", NaN, null and undefined are all falsy.

Async: promises and async/await

async function loadDevices() {
  try {
    const res = await fetch("/api/devices");
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (err) {
    console.error("load failed", err);
    return [];
  }
}

// run in parallel, wait for all
const [parts, log] = await Promise.all([getParts(), getLog()]);

The DOM

const list = document.querySelector("#parts");
list.innerHTML = parts.map(p => `<li>${escapeHtml(p.name)}</li>`).join("");

document.addEventListener("click", e => {         // event delegation
  const btn = e.target.closest("[data-remove]");
  if (btn) remove(btn.dataset.remove);
});

localStorage.setItem("key", JSON.stringify(obj)); // how this site saves your edits
const obj2 = JSON.parse(localStorage.getItem("key") ?? "null");

Escape anything user-typed before putting it into innerHTML, or use textContent. That's how you avoid XSS.

Node, npm and TypeScript

  • Node runs JS outside the browser. npm init -y, npm install pkg, scripts in package.json.
  • TypeScript adds types: function total(parts: Part[]): number. Angular is written in TypeScript, so learning TS pays off there.
  • Angular essentials: components, templates and bindings, services + dependency injection, HttpClient, routing, RxJS observables.
