Java

Your main application language: Spring Boot, JPA, REST, and the robot's control software. This page covers modern Java (17/21 LTS) syntax and the Spring patterns you use most.

Toolchain

  • JDK: use an LTS release (17 or 21). Check with java -version.
  • Build: Maven (mvn clean verify) or Gradle (./gradlew build). Use the wrapper scripts so everyone gets the same version.
  • IDE: IntelliJ IDEA. Learn the refactorings (rename, extract method, introduce variable) and the debugger.

Modern syntax

// local type inference
var devices = new ArrayList<Device>();

// records: immutable data carriers (Java 16+)
public record Device(String host, int port) {}

// switch expressions + pattern matching
String kind = switch (port) {

    default -> "other";
};
if (obj instanceof Device d && d.port() == 22) { ... }

Collections & streams

List<Device> ssh = devices.stream()
    .filter(d -> d.port() == 22)
    .sorted(Comparator.comparing(Device::host))
    .toList();

Map<Integer, List<Device>> byPort = devices.stream()
    .collect(Collectors.groupingBy(Device::port));

int total = parts.stream().mapToInt(Part::cost).sum();

Pick the collection by access pattern: ArrayList (indexed), HashMap (lookup by key), HashSet (uniqueness), ArrayDeque (queue/stack), TreeMap (sorted keys).

Spring Boot REST + JPA

@Entity
@Getter @Setter @NoArgsConstructor           // Lombok
public class Part {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    @Column(nullable = false) private String name;
    private String subsystem;
    private BigDecimal estCost;
}

public interface PartRepository extends JpaRepository<Part, Long> {
    List<Part> findBySubsystem(String subsystem);     // derived query
}

@RestController
@RequestMapping("/api/parts")
@RequiredArgsConstructor
public class PartController {
    private final PartRepository repo;               // constructor injection

    @GetMapping
    public List<Part> all() { return repo.findAll(); }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Part create(@Valid @RequestBody Part p) { return repo.save(p); }
}
  • Keep controllers thin. Put business logic in @Service classes and return DTOs rather than entities once the API is public.
  • Configure via application.yml plus profiles (dev, prod). Keep secrets in environment variables.
  • Security: Spring Security filter chain. Learn the session vs JWT trade-off.
