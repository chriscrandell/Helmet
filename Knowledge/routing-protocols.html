Routing protocols

How a router picks a route, and the quick-reference facts for OSPF, EIGRP and BGP that come up in exams and on the job.

How the route is chosen

  1. Longest prefix match wins first. A /27 beats a /24, which beats the default route, no matter which protocol learned them.
  2. For the same prefix from different sources, the lowest administrative distance wins.
  3. Within one protocol, the lowest metric wins (equal metrics → ECMP load sharing).

Floating static route: a static with a higher AD than the dynamic route (e.g. ip route 0.0.0.0 0.0.0.0 10.0.0.1 250), so it only installs if the dynamic route disappears.

OSPF

  • Link-state, Dijkstra SPF. Cost = reference bandwidth ÷ interface bandwidth. The default reference is 100 Mbps, so set auto-cost reference-bandwidth consistently on every router if you have links faster than 100 Mbps.
  • Areas: area 0 is the backbone, and every other area must touch it. ABRs sit between areas, ASBRs redistribute external routes.
  • Multicast 224.0.0.5 (all OSPF routers) and 224.0.0.6 (DR/BDR). Protocol 89.
  • Timers: hello 10 s / dead 40 s on broadcast and point-to-point. 30 / 120 s on NBMA.
  • DR/BDR on multi-access segments: highest priority wins (default 1, 0 = never), then highest router ID. No pre-emption.
  • Neighbor states: Down → Init → 2-Way → ExStart → Exchange → Loading → Full.

Adjacency won't form? Check that these match: area ID, subnet and mask, hello/dead timers, authentication, area type (stub flags), MTU (stuck in ExStart/Exchange), and that router IDs are unique. Also check for passive interfaces.

EIGRP

  • Advanced distance-vector, DUAL algorithm, Cisco-originated (now an open informational RFC). Multicast 224.0.0.10, protocol 88.
  • Metric uses bandwidth (slowest link) and delay (sum) by default (K1 = K3 = 1).
  • Successor = best path. Feasible successor = backup path that passes the feasibility condition: its reported distance is less than the successor's feasible distance. That makes it loop-free and an instant failover.
  • Neighbors need a matching AS number and K-values, and the same subnet. Authentication must match if it's configured.
  • Unequal-cost load balancing with variance.

BGP

  • Path-vector, runs over TCP 179. eBGP is between autonomous systems, iBGP within one (iBGP needs a full mesh, route reflectors, or confederations).
  • Loop prevention: a router rejects routes that already contain its own AS in the AS_PATH.
  • Best-path order (Cisco, simplified): highest weight → highest local preference → locally originated → shortest AS_PATH → lowest origin type → lowest MED → eBGP over iBGP → lowest IGP metric to next hop → oldest eBGP route → lowest router ID.
  • Influence outbound traffic with weight/local preference. Influence inbound traffic with AS_PATH prepending/MED.
